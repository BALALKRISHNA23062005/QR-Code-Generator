# UPI QR Code Generator

A simple Python project that generates UPI payment QR codes using a UPI ID. The generated QR codes can be saved as image files and displayed directly from the program.

## Features

- Takes the user's UPI ID as input
- Generates a UPI payment URL
- Creates QR codes using Python
- Generates QR codes for PhonePe, Paytm and Google Pay
- Saves the QR codes as PNG images
- Displays the generated QR codes
